# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Search existing issues before opening a new issue.
2. Fork the repository and create a descriptive feature or fix branch.
3. Make a focused change and test the Bash script.
4. Commit with a meaningful message and push your branch.
5. Open a pull request explaining what changed and how it was tested.

## Reporting issues

Please explain the steps to reproduce the problem, the expected behavior, and the actual behavior. Do not include secrets or personal information.

## Community

Please read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and communicate respectfully.
